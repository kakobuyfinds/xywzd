From product link to QC photos

Save the exact variant

Open the CAFANS detail page and find the original marketplace URL. If CSSBuy accepts that listing, record the selected color, size and seller price before ordering.

Check measurements and photos

For shoes, compare the size label, insole length and both soles. For clothing, compare the size tag, chest width and garment length with a piece you already own. Confirm whether the seller measures flat or around the garment.

Compare parcel quotes

Use the same destination and packed dimensions for each quote. Check how each route calculates billable weight, then confirm what the quote includes before choosing a route.

Estimate your parcel total

Enter amounts in USD using your listing and shipping quotes. Include local delivery, agent fees or estimated taxes in the third field if they apply and are billed separately.

CSSBuy spreadsheet FAQ

What is a CSSBuy spreadsheet?

It is a shopping shortlist used to compare product links, categories and reference prices before placing an order through a shopping agent. This independent guide uses CAFANS listings as its catalog source.

What should I do if a listing has changed?

Check the current seller, available variants and price on the source listing. If the link is unavailable, remove that row from your shortlist or find a listing you can verify.

Can I open the results in Excel or Google Sheets?

Yes. Filter the catalog and use the CSV button to export the visible products. The file includes each title, category, reference USD price and CAFANS product link.
